# ADR 0075: 不変の計算入力と現行条件の差分表示

2026-10-14。TS-API-05、WP-02／04／06。状態：実装・ローカル検証済み。製品要件・権限・採用／公開の条件を変更しない。

差分をサーバーで組み立てる。クライアントの設定フォームだけを比較すると、未保存値や部分的なキャッシュを現行条件と混同するためである。既存snapshotのR2 digest・企業／チーム・月・入力版を検査し、不変のlineageから当時の登録版を取得する。現行の適用月・チーム所属・参照雇用区分を選び、登録入力、計算に使う条件、参照版を別の項目として比較する。

元snapshotの取得はジョブ対象・入力版・編集版の変更へ結び付け、計算中／STALEでも比較できる画面接続にする。結果の採用と閲覧を分離し、ジョブ状態ポーリングごとのR2読取を増やさない。

登録値と実効条件を両方表示する。たとえば個人契約の変更が企業・雇用区分との共通範囲を変えなくても、登録版と登録した値の変更を確認できる。同じ値の再登録は参照版の変更だけとして扱う。0・null・未設定は区別し、整数分を丸めない。配列はスタッフID・業務枠・希望の日付／種類などで対応付け、並び替えだけを変更にしない。

現在のルールが矛盾して計算入力を組み立てられない場合は、登録入力と確認できた参照版の差分を返す。導出できない履歴・公開勤務の参照が消えたとは断定しない。画面で組み立て不能を示し、VERIFIED・採用可能とは扱わない。差分閲覧はソルバー・checker・採用・公開を実行せず、過去版・固定・理由を変更しない。

現在の管理権限、enabled・初回変更状態、企業入力版、編集headのID／版を最後の単一D1 SELECTで照合する。閲覧中の失効・版変更は403／409で拒否する。各ページは期待する入力版と編集版を指定し、画面も不一致の応答・古いページを破棄する。既存の保存・採用・公開時の再検証は維持する。

1応答50項目、offset最大1,000,000、表示文字列の先頭1000文字と明示的な省略フラグは実装上の境界であり、製品のスタッフ人数や履歴保存期間の新しい制約ではない。全差分を計算してからページ分割するため、大規模入力での読取性能・CPU／料金は未実測。

実施記録（過去の私有資料・公開対象外）に実API／制御ブラウザーの違い、失敗と修正、終了証跡を記録する。Cloudflare追加実行は0。最終一括確認・backup定期実行保留・30日保管を維持する。

実装時に[Workers Best Practices](https://developers.cloudflare.com/workers/best-practices/workers-best-practices/)と[D1 prepared statements](https://developers.cloudflare.com/d1/worker-api/prepared-statements/)を参照し、公開型定義`@cloudflare/workers-types 5.20261013.1`を作業用cacheで照合した。依存・Wrangler設定・生成済みEnvは変更していない。
