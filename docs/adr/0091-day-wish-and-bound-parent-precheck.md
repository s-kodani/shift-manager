# ADR 0091: 当日希望の評価と親検査済み保存案の再利用

2026-10-14。R-01。状態：等価性の試験済み・規模改善は検証対象。

当日の希望がない場合は未充足0を返し、勤務／休日だけならworkedMinutesの有無で評価する。パターン／時間帯は元の分集合・取消後の条件を維持し、項目ごとの同じ重み・日付・0／未設定を変えない。通常にも適用する。

分離診断の構築だけ、親が全条件・lineageを検査済みの初期ファイルSHAを検査し、入力全体と全assignmentの内容署名へ結び付けたreportを保存案precheckへ再利用する。入力・勤務・役割・版・ファイル変更は拒否し、返却reportはdeepcopyして証明を汚染させない。

任意のPython内部saved_precheck callbackは通常Noneで、従来のfresh checkerを呼ぶ。通常APIにreportや証明を注入する設定は追加せず、親・CP結果・外部HTTP checkerの検査を維持する。trusted SHAを持つだけの任意外部ファイルを信頼する機能ではなく、親所有の検査済みファイルを同じ制御callの中で渡す。

候補・モデル・hint・整数目的・必須条件・通常120秒・Worker許可profile・保存／公開は維持する。計画（過去の私有資料・公開対象外）／実施結果（過去の私有資料・公開対象外）で速度・モデル完成・CP／品質を分ける。
