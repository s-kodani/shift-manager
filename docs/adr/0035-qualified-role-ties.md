# ADR 0035: 同点の初期役割選択で適格な単一役割を維持する

2026-10-12。状態: **技術候補の実装・比較中。製品既定への採用とG0／MVP受入は未完了。** [ADR 0034](0034-interval-aware-hints-and-private-benchmark.md)の区間別初期値・全候補探索・独立検証を維持する。

`balanced-incumbent-v2`の役割選択は、予約量を満たすと「役割なし」と適格役割が同点になり、先に列挙された役割なしを選ぶ。一般業務を処理する資格者でも実際に役割を兼任しなければ比率の分母へ入る（Q77）。後続の一般処理者を加えたときに役割先行不足が増え、登録済み管理専任へ送る初期案となる場合がある。これは実モデル／チェッカーの人数算出とは別の、ヒントの品質課題。

`balanced-incumbent-v3`は、役割先行／同段階の予約利益が同点の場合に限り、適格な単一役割を「役割なし」より先に選ぶ。資格者全員を複数役割へ数えず、勤務中でも一般処理をしていない時間へ役割を付けない。Q76の丸め、Q78の管理専任除外、Q120の同時1役割、役割資格と能力の区別を維持する。これはヒントの選択順で、製品の新しい目的関数や役割の必須制約ではない。

旧候補は再現・比較用に維持する。新候補の初期案も限定探索・独立VERIFIED・モデル評価との一致を経て採用し、その後は全勤務候補・業務・役割で段階探索する。役割なしの選択肢、月最低量、休憩、分単位準備、希望・不足・余剰の順序、既定HTTPの従来方式／20秒を変更しない。後順位の余剰が増える場合は不足改善と分けて記録する。

小規模の役割・業務選択の全列挙、企業丸め／チーム・業務範囲、不適合ヒントからの修正、上位評価保護、混在役割、部分休憩と既存回帰を確認する。大規模は同じ架空入力と手書き比較案を使い、比較案を探索へ渡さない。101／500人・60分と新しい30分計測で、時間・品質・メモリ・証明状態を比較する。

非負目的が0のときの解析的証明による探索時間配分は、別の未実装候補として残す。限定探索のOPTIMALを元問題のOPTIMALへ読み替えない。実施結果（過去の私有資料・公開対象外）を参照する。バックアップ有効化保留・保管30日、メールdisabledを維持する。
