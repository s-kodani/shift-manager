# ADR 0022: 非公開の累積配備検証とAPIキャッシュ禁止

2026-10-11。状態：専用Cloudflareで限定検証済み。一般公開・MVP受入は未完了。

## 判断と理由

画面の余白修正と製品機能を累積配備し、配備された資産と実APIの動作を確認する。既存PoCのBearer保護を維持し、公開範囲を増やさず、専用入口が製品appを内部呼出する。架空データの実認証・CSV／D1／R2操作と終了処理、ASSETS bindingの有界読取・hashだけを返す。外部クライアントは取得したhashを直前のローカルビルドと照合する。これは資産一致の証明であり、リモート描画の視覚受入とは区別する。

実応答の検査で、処理前に設定したno-storeがBetter Authの生Responseのログイン／変更に残らないことを確認した。全APIの処理後に共通middlewareで付ける。認証成功・失敗、セッション・パスワード変更を含めてキャッシュを許さない。認証・権限・初回変更の条件は変更しない。

## 代替案・結果・制約

公開guardを解除する案は専用PoCの認可範囲を超える。秘密の資格情報をクライアントへ返す案も採らない。各handlerだけにno-storeを設定する案は生Response経路の見落としを再び生むため、共通middlewareで適用する。

累積migration0009〜0018、実環境の基盤／小規模計算／実Queues再試行、最終Workerの7ケースと3資産一致、ローカル257件を確認した。実施記録（過去の私有資料・公開対象外）に初回500・CLI7403・復元未実施と残る受入を記録した。製品の一般公開、実端末、全機能受入、性能達成はこの判断に含めない。
