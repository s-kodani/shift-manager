# ADR 0073: 予定参加の全解除で未割当が残る取消の停止

- 日付: 2026-10-14
- 状態: ユーザー決定
- 対象: Q97・Q124、WP-08、TS-DETAIL-08
- 回答: 「取消確定を止め、管理者が先に配置を整えて再確認する（推奨）」

## 確定した扱い

半日取消が研修・会議の一部に重なると、対象者の参加全解除により、取消外の勤務に業務未割当が残る場合がある。この候補は独立チェッカーのWAITING違反で拒否する。公開勤務・受付状態・参加解除履歴・承認通知を変更しない。欠勤事実のREPORTED記録は維持できる。

管理者が先に予定参加と業務配置を整え、必須条件を満たす案を別途公開する。その後、同じ申請を最新の入力版・公開版で再確認し、確定直前にも再検証する。公開済みの出退勤・休憩・月下限を維持し、待機許可・取消時の自動業務追加・同時配置入力は導入しない。

Q97の確定時参加解除は維持する。この補足は必須条件を満たさない候補の停止と事前調整を定めるもので、取消が成功した後の通常再配置・別公開とは別の経路である。管理者の事前予定変更は独立した入力履歴へ記録する。

## 実装と検証の区別

取消候補の未割当拒否は既存実装を維持する。画面へ事前配置調整・別公開・同申請再確認の案内を追加する。実施範囲と未検証はローカル検証記録（過去の私有資料・公開対象外）に記載する。実SDK・認証付きブラウザーの全導線とCloudflare最終受入を、この限定試験で代替しない。
