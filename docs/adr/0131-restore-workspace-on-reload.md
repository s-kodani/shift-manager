# ADR 0131: リロード前の画面を復元する

2026-10-17。ユーザー依頼「リロード前に開いていた画面のまま維持」を反映する。

## 決定

既存の企業・チーム・対象月に加え、サイドバーの画面をURLの `section`、シフト内の「月間シフト／日別業務配置／計算結果」を `tab` に保持する。画面切替と内部導線の両方で、確定した表示状態を `history.replaceState` で現在の履歴へ記録する。タブをまたぐ共通のlocalStorageは使わない。既存のほかのquery・hash・history.stateは保持する。

リロード／URLからの初回表示では、認証後の `/api/context` で企業・チームの所属を確認し、現在の権限で表示できる画面だけを復元する。画面候補と権限フィルターはサイドバーと共用する。不正・未知・権限外の `section` は通常の初期画面（シフト・計算結果、チーム未登録の企業管理者は企業共通ルール）、不正・未知の `tab` は計算結果に戻す。パラメーターのない既存URLもこの初期動作を維持する。

未保存入力の移動確認は維持する。「編集を続ける」の場合は表示・URLとも変更しない。処理中の移動停止・再送・APIの認証認可・保存済みデータ・計算仕様を変更しない。復元対象は画面と表示タブであり、未保存フォーム、スクロール位置、スタッフ選択や過去の計算選択などの個別表示状態は追加保存しない。

## 確認

型チェック・既存クライアント試験・製品buildと、製品資産＋架空GET応答によるブラウザー確認を行う。全8画面、3つの表示タブ、企業／チーム／対象月、不明なURL、スタッフ／チーム管理者の権限外URL、チーム未登録、未保存確認、モバイル幅を対象とする。結果とCloudflare反映範囲は実施記録（過去の私有資料・公開対象外）へ記録する。

## 2026-10-20の画面導線更新

[ADR 0136](0136-schedule-info-and-day-dialogs.md)により、過去再検証のセレクトを削除し、現在判定のタイルと公開情報infoへ整理する。月間／結果の2タブと日付／セル詳細モーダルへ変更し、旧`tab=daily`は月間へ移行する。保存済み記録・公開条件・権限は保持する。以前の実行結果は当時の画面に対する証跡として維持する。

## 2026-10-24の表示更新

[ADR 0138](0138-schedule-action-modals.md)により、月間を常設し、計算結果と公開確認はモーダルへ移す。公開不可理由・対応・入力比較infoは月間カード内の初期折り畳みとし、旧tabパラメータは月間へ統一してURLから除去する。以前の検証結果は当時の画面に対する証跡として保持する。
