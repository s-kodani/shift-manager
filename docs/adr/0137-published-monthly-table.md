# ADR 0137: 公開済みシフトを月間表で表示する

2026-10-20。ユーザーの追加依頼。ADR 0135／0136の管理者向け公開シフトの入口を更新する。権限・公開条件・Q82／Q92・公開後の勤務維持は変更しない。

## 決定

管理者の「公開済みの勤務」を「公開済みのシフト」へ変更し、公開版の保存済み配置を計算案と共通の月間表で表示する。従来の説明文「スタッフ名を押すと、公開済み勤務を確認できます。」と単独のスタッフ名一覧は削除する。計算案がなくても公開表を表示し、公開版のスタッフ集合を使用する。現在のスタッフ設定から過去の公開表の行を増減しない。一般スタッフは従来どおり本人の公開シフトだけを表示する。

表のスタッフ名から既存の月間勤務一覧（公開版を初期選択）、日付見出しから全員の日別配置、記録のあるセルからスタッフ×日付の詳細を開く。休日・取消・未確認を区別し、未確認セルは操作不可。公開版番号・現在／過去を明示し、過去版は閲覧のみ。現在版の明示固定解除は従来の個人別月間モーダルから行う。

詳細は保存済み公開配置を使い、予定・分単位準備／移動は公開時の凍結入力から復元する。取消による公開版はその版に保存された取消検証入力を優先し、通常版は既存snapshot読取APIから当時の入力を遅延取得する。snapshotのID・対象月・入力版を照合し、現在の設定を代用しない。現在版の明示固定は既存fixed読取API、過去版はその版の公開時記録を使う。補足情報の取得失敗でも元の出退勤・休憩・取消・業務は閲覧でき、未取得の固定を「なし」と表示しない。再読込を用意する。

日別配置とセル詳細の表示部品を計算案と共有し、計算案／公開版の表とモーダルの対象を分離する。公開版切替・企業／チーム／月の変更時に公開モーダルを閉じ、旧読取応答を破棄する。背景の未保存編集と既存の固定解除の保護を維持する。

計算履歴選択とタブの下に常設していた単独の「計算完了」欄を削除する。処理中の状態・spinner、計算履歴内の状態、結果の検証・失敗表示は維持する。公開infoの名称も「公開済みシフトの情報」に統一する。

## 検証

実施記録（過去の私有資料・公開対象外）を参照。既存の公開・snapshot・fixed APIを読むだけで、API／DB／計算の契約変更はない。
