# ADR 0021: 需要CSVのプレビューと原子的な正常行反映

2026-10-11。状態：需要の必要人数CSVを限定実装・ローカル検証済み。CSV全体の受入・Cloudflare配備は未完了。

## 判断

Q101のプレビュー後の全件中止／正常行のみ反映を、対象月の必要人数へ接続する。文字列を評価せず、UTF-8・カンマ区切りの固定列を有界に解析する。列順は見出しで解決し、行・列の診断を返す。同一日付・開始・業務IDを更新キーとし、ファイル内の同キーは全該当行をエラーにする。ほかの需要・研修／会議・役割条件は保持する。これは需要の更新キーであり、Q100のスタッフ番号による企業内照合を代替しない。

プレビューで入力版、設定・計画の元版、保存済み固定と例外、操作者・企業・チーム、CSV原文をハッシュで結び付ける。反映時にプレビューを再構築し、同じ版・同じ意味であることを検査する。固定・予定等の必須条件は通常の入力登録検査を通す。新しい計画版、入力版、監査、除外行の理由を含む不変取り込み記録は、単一D1 batchで保存する。同じ操作IDの配送は既存結果へ照合し、別内容や古い版を拒否する。事前検査の途中で同IDの別配送が先に確定した場合も、その結果を照合する。

直接人数と算出済み人数は別々に保存し、直接0を未設定と区別する。人数は既存capacityScaleに整数・小数・分数を正確に変換し、丸めない。業務量からの算出式、精度の採用判断は追加しない。

## 代替案と結果

全件を常に拒否する方式はQ101の選択を満たさない。クライアントの解析結果をそのまま信用する方式は版・固定・参照の更新競合を防げない。巨大な一括書込の新経路は増やさず、既存の版付き入力・原子更新を使う。

専用統合11件、全統合254件、ブラウザと実ローカルWorker/D1/R2の照合に合格。実施結果（過去の私有資料・公開対象外）に実行範囲と制約を記録する。スタッフ／スキル／契約CSV、業務量予測値CSV、Excel、大量ファイルの性能、Cloudflareでの0018配備は未完了。
