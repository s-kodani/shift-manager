# ADR0111: GitHub Actionsの復旧保留とローカル検証継続

- 日付: 2026-10-15
- 状態: ユーザー決定
- 決定: 「CIの復旧は保留し、ローカル検証を進める」

GitHubアカウントの支払い／spending limitにより、Actionsがテスト開始前に停止した記録を維持する。課金設定を変更せず、復旧を開発の待ち条件にしない。既存の機能・型・ビルド・無料DevSecOpsをローカルで実行し、成功／失敗と対象ソースを記録する。保留されたCIを成功へ書き換えない。

これは製品仕様の変更や、未実施の検証を合格にする決定ではない。現行の遠隔起動guardはまだ機能／security CI成功を要求するため、最後のCloudflare前に、実CI成功か、ローカル検証の正式な代替証跡を使う条件を整合させる必要がある。その未完了を明記し、検証を進めるためにmetadataを手編集してguardを通さない。独立レビュー、費用上限と最後のCloudflare一括確認は維持する。

2026-10-15追記：[ADR0112](0112-local-check-evidence-instead-of-held-ci.md)で実ローカル検査入口を追加した。遠隔起動へ代替証跡を渡す候補は、自動承認レビューの拒否により未適用で、現行guardはCI成功を要求する。候補を適用する前に実結果を添えて明示承認を確認する。

2026-10-15承認後追記：[ADR0112](0112-local-check-evidence-instead-of-held-ci.md)の実11コマンド成功を示した確認に対し、ユーザーがローカル証跡による代替を明示承認した。起動guardへ提示差分を適用する。CI保留をsuccessへ書き換えず、独立レビュー／正式凍結／復旧binding／費用上限は維持する。
