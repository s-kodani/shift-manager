# ADR0110: 最終D1確認の所有記録と読取ブラウザー

- 日付: 2026-10-15
- 状態: 実装・ローカル検証済み。Cloudflare未実行

最終一括確認は通常4jobに加えて、D1の0行更新・版競合・原子取消・公開との並行競合・途中SQL失敗を確認する。既存の架空PoC検査にUUIDを渡し、PoC専用の`final_d1_probe`へ実行受付と結果を保存する。同IDの実行は一度だけ受け付け、通信断後は結果照会だけを行う。正常／失敗の終端と、そのUUIDの架空行が0件になるまで所有終了を認めない。製品migration0033、必須条件、数理処理は変更しない。

ブラウザーのローカル／遠隔入口は共通の読取コードを使う。同一originのGET／HEADだけを許し、PoC tokenを別originへ送らない。PCは101人の月間表が描画され、先頭が画面内に入ったことを確認する。本人画面は31日の公開勤務が表示され、読込表示が消えたことを確認する。DOMの存在や見出しだけで合格にしない。

今回、最初の画像はPCが別の上部パネル、本人が読込中だった。待機条件修正後もPCのスクロール直後が空白になったため、表先頭の位置と描画フレームを待つ条件へ修正した。原画像を診断記録として保持し、修正後の2画像を目視した。製品UIの変更ではない。

新しいローカルSDKのD1検査と、過去4jobの架空コピーを表示する別ローカルWorkerで確認した。同じ新cohortの4job全体反復やCloudflare互換性の達成としない。実施結果（過去の私有資料・公開対象外）。
