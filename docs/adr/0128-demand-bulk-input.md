# ADR 0128: 期間・曜日・時間帯を指定する需要の一括入力

2026-10-17。ユーザー依頼「指定した期間は同じ条件で一括登録できるようにしたい」を反映する。

## 決定

需要管理に、開始日・終了日（両端を含む）、対象曜日、毎日の開始・終了、一般業務、直接必要人数をまとめて指定する入力を追加する。対象は選択中の暦月内。同じ必要人数を毎日の時間帯へ適用し、チーム設定の30分／60分枠へ展開する。時刻はHHMM、終了2400を許容する。曜日は初期状態で全曜日を選択する。祝日判定や営業時間の自動補完は追加しない。

反映前に対象日数・枠数と追加／上書き／保持件数を表示する。既存枠は日付・開始・業務で照合し、初期選択では既存値を保持して未登録だけ追加する。管理者が上書きを選んだ場合も、直接必要人数だけを変更し、参考の算出値（0を含む）を保持する。他の業務・日付・時間帯、研修・会議・役割条件は維持する。0人と未設定は区別し、未入力人数を0とみなさない。Q64〜Q66の能力換算人数・直接値優先・60分枠の扱いを維持する。

対象月外・不正日付・逆順期間・曜日未選択・該当日なし・時間の逆転／日またぎ・配置枠に合わない端点・対象外業務・人数未入力／精度違反／既存の人数上限超過は反映前に拒否する。期間・条件や既存需要の編集後はプレビューを無効にする。

「一括入力を反映」は月次フォームへの反映であり、「この月の入力を保存」で永続化する。個別の枠を複数回API保存する方式は採らず、既存の月次保存を1回使う。版競合・権限・原子的保存・サーバー検証を維持し、API契約・DB・最適化モデルは変更しない。一括入力の編集中・反映後の未保存保護を維持し、未反映の条件が残っている間は月次保存を拒否する。保持だけで変更0件の場合は反映を無効にし、リセットで編集中の条件を破棄できる。
