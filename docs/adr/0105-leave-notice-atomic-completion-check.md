# ADR 0105: 受付・却下の原子完了と既読の実保存を確認する

- 日付: 2026-10-14
- 状態: 採用・ローカル検証済み／Cloudflare未配備
- 対象: R-03／04／06、TS-OPS-08・TS-API-04・TS-AUTH-05

休暇／本人欠勤申請／管理者欠勤事実の受付と本人申請の却下では、SQLが例外なく終了してもrecord・決定・head・audit・本人noticeが欠落し得た。同batch末尾で企業・チーム・本人・操作ID、入力内容、状態・版、監査と通知を結合確認し、欠落時はSQL失敗で全D1変更をrollbackする。公開勤務と入力版は変更しない。同IDの修復後再送と重複防止を維持する。

受付・却下・承認・欠勤取消確定の既読は、UPDATEの0行を成功と仮定せず、所属再確認後に本人noticeの実read_atを確認する。未保存ならNOTICE_UPDATE_FAILED／503を返し、画面のAPIメッセージに再試行案内を追加する。既読済みの再送で時刻を変えない。公開通知は既存の実read_at確認で拒否できており、その挙動は変更しない。

計画（過去の私有資料・公開対象外）／実施結果（過去の私有資料・公開対象外）へ故障注入前後・HTTP応答・回帰を記録する。schema・認証方式・勤務／取消条件は変更しない。SQL故障の制御checkerと実native制約検査、ブラウザー描画、Cloudflare確認を区別する。最終一括配備方針とbackup HOLD／30日を維持する。
