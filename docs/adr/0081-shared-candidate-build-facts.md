# ADR 0081: 候補適格性と準備区間の検査を共有する候補

2026-10-14。R-01。状態：技術候補・通常未採用。全候補・本体制約・目的・整数分を維持する。

同じsolve入力の普通のdraft日だけ、曜日適格性・契約開始／終了・全層日上限が同じ場合に候補検査を共有する。予定・固定・例外・勤務不可のあるstaff-day、公開済み再配置は元の検査を使う。候補の休憩・取消配列はコピーし、返却後の変更を他の日へ漏らさない。week／month・skill／role条件は従来の本体で検査する。

準備区間の可否indexは、候補分集合の順序・枠・準備長が同じ場合だけ共有する。各staff-dayの変数・制約は別に生成し、両優先順位・30／60分で初回full CP protoとhintの一致を確認する。共有は一つのsolve内に閉じる。

診断`mvp-joint-shared-build-v1`だけcalendar／compact／shared flagを有効にし、構築の技術ガードを100万→350万変数にする。通常の100万ガードは維持。120秒・CPU1・6 GiBは増やさず、単なる変数枠拡大を受入成功としない。

実施結果（過去の私有資料・公開対象外）では101人の評価維持、構築38.92→29.58秒、500人の候補生成51.95→10.88秒を確認した。500人は配置制約構築108秒で未完了・UNKNOWNのため通常採用は保留。次に継続時間の表現を等価性検証して調べる。候補削減・ルール緩和・目的順序変更で通さない。

Cloudflare追加0、最終一括、定期backup保留・30日、試験導入範囲外を維持する。
