# ADR 0072: 今回のMVP開発と試験導入の範囲

- 日付: 2026-10-13
- 状態: ユーザー決定
- 根拠: 「試験導入は今回のMVP開発のスコープ外として進めてください」

2026-10-14追記：[ADR 0097](0097-defer-operations-mail-ai.md)で運用・メール・AIを後続工程へ移した。以下は2026-10-13時点の決定であり、今回の最新完成条件はADR 0097と残タスク一覧を優先する。

## 今回の完了条件

今回の目標はMVPの製品実装・技術検証・品質ゲート・運用準備を完了すること。実チームへの導入、現場の1か月評価、現行運用との作業時間比較と本開発の再見積もり（A3〜A4／G2、R-08）は今回の納品条件に含めない。試験チームの人数・業務・責任者の回答を今回の開発の前提として待たない。

G0のモデル採用とG1の技術的な開始準備は維持する。認証・権限・原子更新・独立検証・公開後操作・入力／出力・画面・故障復旧・監視／手順・最終Cloudflare確認の未検証を、試験導入除外の理由で合格にしない。実端末確認は製品UIの検証と現場受入を区別する。費用を抑えるローカル優先・最終Cloudflare一括、定期バックアップ有効化保留、30日保管は維持する。

## 変更しないもの

確定製品仕様・権限・制約・公開判定・取消・AI・メール用途を変更しない。A3〜A4／G2はプロジェクトの後続工程として残す。試験チーム・現場評価とG2の達成を架空データで代替しない。旧実施記録の「G0〜G2未達」は当時の範囲として保持し、現在の完了判定はこの決定と最新残タスクに従う。
