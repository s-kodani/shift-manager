# ADR 0136: 公開情報・判定タイル・日別詳細の表示

2026-10-20。ユーザー承認の画面整理。ADR 0017・0131・0135の画面導線を更新する。検証・権限・公開条件・Q82／Q92は変更しない。

## 決定

シフトページの見出し・対象月選択の直下で、管理者・スタッフとも「自分へのシフトのお知らせ」を最初のカードにする。公開勤務の見出し右横のinfoに公開版・日本時間の公開日時、当時の入力版・公開元、現在の検証状態・対象入力版・実検証入力版を移す。スタッフには元のAPIが許可する公開版・日時・状態だけを表示する。過去公開版の表示中は現在の判定を混在させない。対応が必要な警告はカード内に残す。

再検証の過去判定セレクトと履歴一覧取得を画面から削除する。過去判定は原因調査用であり、以前の判定への復元操作ではなかった。記録とAPIは保持する。現在の判定を検証状態・一般業務不足・同段階の担当区分不足の3タイルで表示する。検証済みは緑、待機・実行中・失敗・履歴不足・入力不整合・必須違反は赤。不足は0なら緑、正なら赤。数値は現在の公開版・対象版・検証入力版・状態が一致し採用済みの証明だけを使う。公開時の検証が現在も有効なら元の公開証明を使う。読込中は中立色、未取得は理由付きの赤にし、欠損を0にしない。失敗再試行・記録再読込・旧応答破棄を維持する。

月間／計算結果の2タブとし、月間の日付見出しから全員の日別業務配置モーダルを開く。対象日はモーダル内で変更できる。記録のあるセルからスタッフ×日付の閲覧モーダルを開き、休日・勤務、パターン、出退勤、休憩種別・時間、勤務量、取消、業務・担当区分、明示固定を表示する。希望・勤務不可は追加しない。未確認セルは操作不可。スタッフ名からの月間勤務一覧と現在公開版の固定解除は維持する。

日別詳細は表示中の計算案／保存済み編集案と古い案の状態に従い、企業・チーム・月・案が変わると閉じる。背景編集を保持し、Escape・閉じる・フォーカス制御を既存Radix Dialogで実現する。旧`tab=daily`は`monthly`へ移行し、モーダルはURLへ保存しない。

手動編集カードは初期折り畳みとし、フォームをマウントしたまま開閉する。非表示でも未保存編集の保護は有効。必須違反の編集対応リンクからは自動展開して移動する。

## 検証と制約

ローカル検証記録（過去の私有資料・公開対象外）を参照。公開API・DB・計算・独立検証の変更はない。追加依頼によるWorker／画面資産のCloudflare配備結果は同記録の末尾を参照。遠隔計算は実施していない。

## 2026-10-24の表示更新

[ADR 0138](0138-schedule-action-modals.md)により、月間を常設し、計算結果と公開確認はモーダルへ移す。公開不可理由・対応・入力比較infoは月間カード内の初期折り畳みとし、旧tabパラメータは月間へ統一してURLから除去する。以前の検証結果は当時の画面に対する証跡として保持する。
