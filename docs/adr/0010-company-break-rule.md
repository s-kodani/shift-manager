# ADR 0010: 必要休憩ルールの企業共通版

- 日付: 2026-10-11
- 状態: 限定実装・ローカル検証済み。製品全体の受入は未完了
- 根拠: 設計Q70、Q99、Q118、Q130／131。製品仕様の変更ではない

## 判断

必要休憩の算定基準・閾値・必要分数・相対取得範囲を既存の`company_policy`へ格納する。企業管理者だけが適用開始月を指定して変更する。チーム管理者は所属チームの共通参照APIから読み、チーム設定へ同じフィールドを送ると拒否する。勤務パターンの固定／自動区分・固定休憩時刻はチーム設定に保持する。

計算入力の`breakRule`は対象月の企業共通版から生成する。企業入力版の競合判定・D1の権限再確認・監査の原子更新を継続し、新しい計算入力には企業共通休憩の参照版を記録する。ソルバー／独立チェッカーの入力契約、正確な整数分、固定は必要量以上・自動は必要量一致の仕様は変更しない。

## 旧版の扱いと代替案

旧チーム版・旧企業版・R2の凍結入力を更新しない。読み取り専用の互換スキーマで旧チームの休憩フィールドを受け、現行チーム設定の応答からは除く。旧企業版の休憩未設定は管理者に表示できるが、計算入力を作成できない。管理者が企業共通値を明示登録する。

チーム間で異なる旧値から一つを選ぶ自動移行、仮設定の初期値、チーム上書きは採用しない。利用者の勤務条件を推測して変えるためである。旧凍結入力は整合性検証付きで過去表示を継続し、企業共通休憩の参照版がない場合は再計算用の現行入力として拒否する。同じ企業入力版であっても作り直しが必要となる。

## 検証・残課題

実施記録（過去の私有資料・公開対象外）に二つのチーム、適用開始月、旧版保持、未設定拒否、APIの権限・上書き拒否、更新途中の権限取消、旧凍結入力のジョブ受付拒否、フォームから実計算への接続を記録する。今回の変更を専用Cloudflareへ再配備していない。公開済み月への設定変更と再検証、実チーム受入、全MVP導線は後続とする。
