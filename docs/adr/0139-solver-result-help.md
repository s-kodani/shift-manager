# ADR 0139: 探索結果タイルの説明ポップアップ

日付: 2026-10-24。ユーザー依頼に基づく。

## 決定

計算結果モーダルの「探索の結果」タイルで、結果文言の右横にinfoアイコンを置く。既存の結果文言を維持し、5つのソルバー状態、手動編集案、想定外の状態値に対応する説明を表示する。FEASIBLEの「未証明」は、同じ入力条件・優先順位でこれよりよい案が存在しないことを確認できていない意味とし、制約検証の状態と区別する。時間切れを実際の終了理由として断定しない。

説明は「探索結果の説明」のヘッダー、状態バッジと結論カード、意味の説明、背景色付きの具体例カード、制約検証への案内で構成する。具体例は必ず「説明用の例」と表示し、実際の計算値へ置き換えない。全文は製品の`solver-result-help.tsx`に保持する。例えばFEASIBLEは「希望100件中90件がかなう案は見つかったが91件以上が可能か未確認」、OPTIMALは「ほかの優先条件を守ると90件が上限と確認できた」と説明する。想定外の状態値は意味を推測せず、具体例を表示しない。

幅420px、モバイルは左右16px以上、本文14px・行間1.7、結論16pxとする。有効案と最良値確認済みは青、案未発見と解なしは黄、モデル検査失敗は赤、手動編集と説明不能はグレーを用いる。色に加えて状態の文字を示す。数値と重要な意味を太字にし、長い説明は内部でスクロールする。

既存InfoHelpの結果用variantを使い、ホバー・フォーカス・クリック・タップ・Enter/Spaceで開く。閉じるボタン・Escape・外側操作で閉じる。Tabで説明の閉じるボタンへ移り、Shift+Tabでアイコンへ戻る。閉じるボタンとEscapeはアイコンへフォーカスを戻し、説明が開いている場合のEscapeは計算結果モーダルを閉じない。対象案・状態・入力版が変わった際に説明を引き継がない。

結果用ポップアップのPortalは計算結果モーダルのContent直下に置く。body直下のままでは背景扱いとなるフォーカス・ポインター・スクロール制御と競合するためで、モーダルのtransformによる座標系の差を位置計算で補正する。既存設定用ヘルプのPortal・操作は維持する。

API・DB・最適化・独立チェッカー・公開可否の判定は変更しない。Cloudflareへの配備・追加計算は行わない。

## 検証

実施結果と再実行手順（過去の私有資料・公開対象外）。全状態の文言、例と色、読み上げ名、キーボード、タッチ、画面端と内部スクロール、背景編集の保持、書込APIなし、既存設定ヘルプと計算結果モーダルの回帰をローカルで確認する。
