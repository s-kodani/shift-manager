# ADR 0138: 公開確認・計算結果モーダルと公開不可案内の折り畳み

2026-10-24。ユーザー承認の画面整理。ADR 0124・0131・0135・0136の画面導線を更新する。公開条件、Q82／Q92、独立検証、版照合、権限、計算仕様は変更しない。

## 決定

シフト計算カードの「シフトを計算」の右隣に「シフトを公開」を置く。表示中の計算案／保存済み編集案が既存の公開条件を満たし、対象データと公開版を取得できている場合だけ有効にする。処理中・応答未確認・同時計算中は無効にする。人数・担当区分の不足だけでは公開不可にしない。

公開ボタンは確認モーダルを開く。現在条件での再検証の説明、不足がある場合の警告・確認チェック、「再検証して公開」を表示する。不足確認が未チェックなら確定不可。開くたびに確認をリセットする。公開先・入力版・編集版・公開版とoperationIdによる既存の保存・再送を維持し、公開成功でモーダルを閉じて公開版を更新する。失敗と同一操作の確認はモーダル内でも表示する。未保存編集の保護を維持する。

月間／計算結果タブを廃止し、月間を常設する。月間シフトカードのタイトル直下に公開不可案内を置く。「この案は公開できません」は常設し、理由・対応・入力比較infoは「公開できない理由・対応を確認」の初期折り畳み内へまとめる。公開可能なら案内自体を表示しない。「計算ボタンへ」は削除し、設定・勤務履歴への導線を維持する。案・月・チーム・画面変更や再読込で閉じ、同じ案の定期更新では開閉を維持する。

表の直下の「計算結果」から、集計・不足・検証結果と配置結果の説明を閲覧モーダルで開く。結果・凍結入力の未取得時は無効にする。案を得られなかった結果も、取得済みなら閲覧可能。読込中・取得失敗・計算中の表示と、画面内の手動編集を維持する。

両モーダルはRadix Dialogを使い、背景の編集を保持し、閉じる／Escape／フォーカス復帰／内部スクロールに対応する。案・入力版・公開版が変われば閉じる。旧`tab=monthly/result/daily`と不明なtabは月間へ統一し、URLのtabを除去する。他のquery・hash・画面復元は維持し、モーダルをURLへ保存しない。

## 検証

検証記録（過去の私有資料・公開対象外）。公開案内、旧URL復元、日付・セル詳細の既存試験を更新し、公開確認・結果モーダルの状態とPC／モバイルを追加確認する。ローカル検証とCloudflare配備を区別する。
