# ADR 0134: 需要・担当区分の必要人数を表形式で編集する

2026-10-19、ユーザーの依頼により、需要管理の「必要人数」と「担当区分の必要人数」を、1条件1行の編集可能なData Tableに変更する。月全体を配置枠ごとのカードで表示する場合の縦スクロールを削減する。

日付、需要の業務、担当区分の対象範囲・区分で絞り込み、日時順の昇順／降順と25／50／100件のページ表示を選べる。表は高さを制限し、見出しを固定する。狭い画面では表内を横スクロールする。個別追加時は絞り込みを解除して追加行のページを表示する。

2026-10-20、ユーザーのレイアウト改善・アイコン化の依頼により、ページ操作は上段に件数・表示件数選択、下段に先頭／前／ページ数／次／末尾をまとめる。表示ラベルは「表示件数」に短縮し、選択欄の読み上げ名には一覧名を残す。4つの移動ボタンは日本語の読み上げ名・titleを持つ44×44pxのアイコンボタンとし、狭い画面でも同じ行に並べる。狭い画面ではページ数の「ページ」を視覚的に省略する。

表示中の行だけでなく、月全体の下書きを既存の保存処理・検証に渡す。ページ外の不正な値も保存を拒否する。直接人数の0／未設定、算出値、比率、役割の評価順序、研修・会議、期間一括入力、見出し別保存と権限の仕様は変更しない（Q76〜78・Q80・Q114・Q119〜120・Q122）。最適化モデル・API・DB形式の変更はない。

ページ切替でDOMに存在する入力が変わるため、表と表示条件を`data-settings-virtual`で囲み、見出し別フォームのDOM比較から除外する。月全体の既存のfingerprintで編集状態を判定する。表示条件の変更だけでは未保存にせず、絞り込み日付のEnterで保存を起動しない。

実装・検証記録は必要人数の表形式編集（過去の私有資料・公開対象外）を参照する。Cloudflare配備・実API保存の確認は別工程とする。
