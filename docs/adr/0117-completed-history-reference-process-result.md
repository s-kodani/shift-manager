# ADR 0117：正常完了した履歴不足の参考案をプロセス境界で保持する

2026-10-15。Q81の既存仕様を満たす修正。製品仕様・目的関数・計算予算・MVP範囲は変更しない。

## 決定

通常計算の子プロセスが正常完了した場合は、親の独立チェッカーで既知の必須違反がなく、履歴不足だけが残る案を `HISTORY_UNVERIFIED`／`BLOCKED_A1` として返す。入力系譜・目的値・子の自己判定と親の実判定を照合し、親判定も実際の状態を記録する。Workerは停止を確認し、別の `/check` で再検査してから参考結果を保存する。参考下書きは作成でき、公開は拒否する。

履歴不足の案を `VERIFIED` のcheckpointへ読み替えない。子のcheckpoint callbackへ渡さず、強制期限時の回収と早期CHECKED hintは引き続きVERIFIED限定とする。Workerでも期限結果の親判定と別検査の両方にVERIFIEDを要求する。INVALID・目的値改変・系譜不一致・停止未確認を受け入れる条件は追加しない。

## 理由と代替案

実装者以外のG0レビューで、参考案をcheckpoint検査が例外にし、さらに正常完了結果の親検査も拒否する問題が見つかった。1人の架空fixtureで、直接計算はOPTIMAL／HISTORY_UNVERIFIED、callback付きはCHECKPOINT_NOT_VERIFIED、通常processは子exit1／PROCESS_EXECUTION_FAILEDになることを実再現した。

全参考案を拒否するとQ81を満たさず、全結果をVERIFIEDへ変えると公開判定を壊す。正常完了と期限checkpointの境界を分け、独立検査の実状態を維持する方式を採る。
