# ADR 0126: 時刻の直接入力をHHMMの数字4桁へ統一する

2026-10-16。ユーザー指定により、コロン付きの時刻を直接入力していた画面は数字4桁のHHMM（例：0930）へ変更する。

対象は需要・研修／会議・役割条件、勤務不可・希望時間帯、手動編集の休憩・役割区間・勤務不可例外、追加受付の終了時刻。共通のテキスト入力に数字キーボード指定、最大4桁、形式・分・範囲の検証を付ける。既存の選択式時刻は維持し、一覧や勤務時間の表示はHH:MM、CSVテンプレート・取り込みの時刻形式もHH:MMを維持する。

0000を当日の開始、2400を当日の終了として扱い、2401や0960、3桁の930は受理しない。休憩・希望時間帯の30分条件、需要の30分／60分配置枠、研修・勤務不可・役割区間の整数分精度と区間順序を維持する。APIへは従来どおり整数分を送る。

手動編集は入力途中の文字列を一時保持し、検証できた値だけを分へ変換して編集データへ渡す。部分入力・空の必須欄・不正時刻のまま以前の値を保存する操作をブラウザーのフォーム検証で拒否する。未保存入力保護を維持する。

追加受付は日付とHHMM入力を分け、終了時刻は0000〜2359とする。従来の日本時間への変換・終了日時のAPI表現は変更しない。

実装・検証記録（過去の私有資料・公開対象外）に確認範囲を記録する。Cloudflareへの配備、DB・最適化仕様の変更は含まない。
