# ADR 0085: 構築用集計の解放を試し、不採用とする

2026-10-14。R-01。状態：検証済みの不採用案。通常コードへの解放処理は撤回した。

500人の初期案CP開始後OOMに対し、目的制約と目的式の生成後、以後使わない11個の集計コンテナ（cap／den／counts／worked／working_days／preferences／shortage／surplus／first／same／boundaries）をclearする案を検証した。モデルproto・目的式・候補・hint／抽出用データは保持した。

小規模のfull proto／hint・実CP評価・独立checkは一致した。しかし500人で解放前後の子RSSは4,002,086,912→4,002,611,200 bytesと減少せず、観測間に約3.81秒を追加した。初期hint完了時には予算がなく、CPを実行できずUNKNOWN／NOT_RUNで終了した。OOM0をOOM解消の証拠にしない。

通常経路へ追加する根拠がなく、解放関数と呼び出し・実験専用テストを撤回し、実測sourceを非公開artifactへ保持した。強制gc／allocator操作や資源増量は導入しない。候補・条件・目的・設定は維持する。

この実験でCP予算0の場合にもcpStart／cpEndを観測していた不備を確認した。実際にCPを呼ぶ場合だけ記録する修正と境界テストは最終コードへ残す。計画（過去の私有資料・公開対象外）／結果（過去の私有資料・公開対象外）に実験sourceと最終source・試験範囲を分けて記録する。

次は選択候補が厳密に一つである条件を使い、準備不可の同じ条件を候補ごとに反復する制約を等価な候補maskへまとめる案を検証する。未実装・未検証。Cloudflare追加0、最終一括、定期backup保留／30日、試験導入範囲外。
