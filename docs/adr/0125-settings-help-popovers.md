# ADR 0125: 設定項目の平易な説明とinfoポップアップ

日付: 2026-10-16。ユーザー依頼に基づく。

## 決定

企業共通ルール、カレンダー、チーム、勤務契約・雇用区分、需要・予定・役割条件、勤務履歴、勤務不可・希望、編集・固定などの設定見出し・入力ラベルの右横にinfoアイコンを置く。説明は平易な日本語と例で示し、勤務時間の分換算、必要人数の0と空欄、習熟度と処理能力の違い、希望締切の前月適用、履歴の確認済み休日0分など、誤解しやすい条件を明示する。説明は設定値や権限を変更しない。

ホバー・フォーカスで表示、クリック・タップ・Enter/Spaceで開閉する。ポップアップ上にポインターを移しても読めるようにし、閉じるボタン・Escape・外側操作で閉じる。閉じるボタンとEscapeでは説明アイコンへフォーカスを戻す。画面端で位置を調整し、PC・モバイルで画面内に収める。説明の参照はdisabled fieldset内でも使えるよう、キーボード操作できるbuttonロールの独立したトリガーにする。

入力欄のラベルと説明ボタンを別にし、ラベルのクリックで入力欄へフォーカスする関係、読み上げ名、既存の未保存入力確認を維持する。説明はPortalでフォームの外へ表示する。操作で入力・チェック状態・保存・計算・公開を自動変更しない。

勤務履歴の「追加する確定履歴の日付」は、ユーザー指定の「一覧にない前月・翌月の勤務日を追加」へ変更する。追加ボタンは「選択した日付を一覧に追加」とし、既存の日付制限・根拠入力・保存の処理は維持する。

## 検証

2026-10-16追加：ユーザー指定により「勤務分」を「勤務時間(分)」へ変更し、入力ラベル・読み上げ名・説明・案内を統一する。変更・検証・反映記録（過去の私有資料・公開対象外）。

同日追加指定：履歴の入力ラベル・読み上げ名・説明見出しから日付の接頭辞を外し、「勤務時間(分)」「確認の根拠」とする。日付は各行の見出しと入力グループに残す。

実施・反映記録（過去の私有資料・公開対象外）に、実行したテストとPC/タッチの表示確認を記録する。API・DB migration・Container・最適化の変更は不要。
